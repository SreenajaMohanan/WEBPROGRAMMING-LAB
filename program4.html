CSS - Cascading Style Sheet

Inline CSS

The paragraph uses Inline CSS attribute. Inline CSS involves adding style properties directly into individual HTML elements using the style attribute.

Internal CSS

This paragraph uses Internal CSS. It is a method used to style a single HTML page by placing CSS code directly inside a style tag within the head section of the document.

External CSS

The External CSS is a method of styling a website where all CSS rules are written in a completely seperate file & it is connected to one or more HTML documents.
